# Timetracker

Ein einfacher Zeitmesser für die Arbeit. 

## Nutzung

Öffne `index.html` in einem Browser. Gib den erwarteten Arbeitsschluss und optional die Startzeit ein. Mit **Start** beginnt die Messung, **Stop** beendet sie. Auf Basis der angegebenen voraussichtlichen Endzeit und des Stundenlohns zeigt ein Ladebalken den Fortschritt sowie den verdienten Betrag in Echtzeit an.
