# Timetracker

Ein einfacher Zeitmesser für die Arbeit. 

## Nutzung

Öffne `index.html` in einem Browser. Gib den erwarteten Arbeitsschluss und optional die Startzeit ein. Mit **Start** beginnt die Messung, **Stop** beendet sie und erlaubt einen neuen Durchgang. Ein Ladebalken zeigt den Fortschritt, zusätzlich werden verbleibende Zeit und der verdiente Betrag in Echtzeit dargestellt.
